## Hey, I’m Aryan 👋

I’m a builder who learns by shipping.

I focus on creating **automation-first products** and **AI-powered tools** that solve real problems — not just demos. Most of my learning comes from building end-to-end systems, breaking them, fixing them, and shipping better versions.

I believe the fastest way to learn engineering is to **build real things**, connect real services, handle real edge cases, and iterate in public.


| 🚀 What I’m into | 🛠️ How I build | 📍 Currently |
|-----------------|---------------|-------------|
| Shipping MVPs that actually work | Ship early, iterate fast | Deepening system automation |
| AI-powered automation (voice, vision, workflows) | Practical solutions > perfect theory | Improving reliability & UX |
| Turning ideas into real products | Build for scale, learn from failure | Building production-grade systems |


> Learning by building. Shipping by default.
